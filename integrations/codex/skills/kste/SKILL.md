# KSTE 한국어 기술문서 작문

<!-- codex:control:begin -->
## Codex 상태 명령

- `/kste on|off|default|strict|status|last`, `$kste on|off|default|strict|status|last`, `t1 on|off|status` 요청이면 MCP `kste_state`를 호출합니다. `args`는 인자를 나눈 문자열 배열, `cwd`는 현재 프로젝트 작업 디렉터리입니다. 인자가 없으면 상태를 조회합니다. 80은 default의 별칭입니다. T1 엔진은 Kiwi입니다. 플러그인 설치에서는 신뢰한 첫 세션 hook이 엔진·모델을 준비합니다. 수동 준비는 KSTE 저장소의 `node scripts/install-t1.mjs`로 합니다. 설치와 on/off 설정은 별개입니다.
- hook에서 처리한 명령은 다시 실행하지 않습니다. 상태 명령은 결과만 알리고 문서를 고치지 않습니다. `/kste`가 명령 메뉴에 없으면 `$kste` 또는 `/prompts:kste`로 호출합니다.
- 문서를 쓸 때 먼저 상태를 조회합니다. 기본은 KSTE on, default 모드, T1 on입니다. default(별칭 80) 명령은 KSTE와 T1을 함께 켭니다. off이면 아래 KSTE 자동 작문 지침을 적용하지 않습니다. 명시적 검사·교정 요청은 수행합니다. strict이면 엄격 모드를 적용하고, MCP 검사 `t1`은 현재 설정의 on/off에 맞춥니다. 별도로 설정한 t1 off는 default를 다시 실행하기 전까지 유지합니다.

제1원칙: 독자가 추론할 것을 남기지 않습니다. 조사와 서술어를 채우고, 어려운 말을 풀고, 한 문장에 한 뜻만 담습니다. 짧게 쓰는 것이 목적이 아닙니다.

## 등급
- error: 전부 고칩니다. 이중피동(되어지다), 서술어 없는 문장, `-할 것/-바람` 지시, 확정형 번역투(`에 있어서`), 같은 뜻 겹침, 용어 불일치, 숫자 누락.
- warn: 대표 항목만 고칩니다. 길이(절차문 17어절, 서술문 21어절 이상), 명사 연쇄 4어절 이상, 조건 후행, 동작 3개 이상.
- 한국어 `.md` 를 쓴 뒤 `npx kste check <file>` 을 실행합니다. error가 있으면 지적된 줄만 고칩니다. 전체를 다시 쓰지 않습니다.

## 템플릿
- 공식: [조건절]? [대상]을 [방법]어 [동작]세요. 결과는 한 문장.
- 절차문 골격: 1 `N을 V세요` 2 `N에서 N을 V세요` 3 `N을 V ㄴ 후 N을 V세요` 4 `N을 V어 V세요` 5 `N은 수치 이내로 V세요` 6 `N을 V지 마세요` 7 `조건면 N을 V세요` 8 `N의 원인이 됩니다` 9 `N을 V ㄹ 수 있습니다` 10 `N이 V어 있습니까?`
- 종결: 지시 `-세요`(금지 `-지 마세요`), 설명 `-ㅂ니다`, 의무 `-어야 합니다`. 한 문서에 한 체계. 보고서는 `-ㄴ다`.
- 조건 선행: 조건은 앞, 지시는 뒤. 한 문장에 조건 하나.
- 항목당 동작 2개 이하. 셋이면 항목을 나눕니다.
- 경고문 3단: `[경고]` 라벨은 블록 머리에만, 정의문 한 번, 항목은 `[조건] 지시. 결과.` 한두 문장.
- 3개 이상 나열은 세로 목록. 순서가 있으면 번호 목록.

## 통제 동사 17
사용하다, 설치하다, 연결하다, 확인하다, 누르다, 넣다, 보관하다, 열다, 켜다, 제거하다, 설정하다, 빼다, 선택하다, 연락하다, 닫다, 청소하다, 닦다. 같은 동작은 한 동사로 통일합니다. 행위자가 있으면 능동으로 씁니다.

## 실무 기준
`에 대하여`, `을 통해`, `N 시`, `업로드` 같은 통용 표현은 고치지 않습니다. 틀린 것만 고칩니다. 코드, 명령어, 파일명, URL은 그대로 둡니다.

## 재작성 정보 보존
숫자, 단위, 부정어(않다, 없다, 금지, 말다), 고유명사, 문장을 지우거나 바꾸지 않습니다. 짧아졌다고 통과가 아닙니다. 확인은 `kste diff 원문 수정문`. 의심스러우면 원문을 남깁니다.

기계가 못 보는 것(위험 수준, 지시어 대상, 주어 복원, 중의성)은 사람이 확인하도록 남깁니다. 규칙 전문: [references/rules.md](references/rules.md)
